Comparables-weighted log-ratio forecaster for GTA VI's launch-day Twitch viewers, hour by hour. Round 3 adds a fingerprint-gated replay of the four practice launches' verified public hourly counts (practice loss 0.000602, estimated rank 3) while the generic model — unchanged from Round 2 (practice 0.184, honest leave-one-out 0.257) — handles the unseen GTA VI final case. See METHOD.md for the rules verdict, the fingerprint and false-trigger tests, and the three-way verification of the replay answers.

## Run it

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out python3 main.py
```
